Why data not saving? 99% is Firestore Rules.

Go to this link and fix:
https://console.firebase.google.com/project/gi-nipo/firestore/rules

You will see something like:
allow read, write: if false;

Change to this and click Publish:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if true; } } }

Then come back here and click Test Write - should say ✅ SUCCESS.
If you see "Firestore not created", go to Firestore link and click Create Database > Test Mode.
